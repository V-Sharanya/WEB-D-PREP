
# 🏆 Hackathon Problem Statement

## 🧩 Title

**Smart Campus Life Manager (SCLM)**

---

## 📌 Problem Overview

In modern universities, students rely on multiple disconnected platforms—ERP systems, messaging apps, emails, and physical notice boards—to manage their academic and extracurricular activities. This fragmentation leads to:

* Missed deadlines and events
* Inefficient communication
* Lack of centralized visibility
* Poor time and task management

There is a need for a **unified, intelligent platform** that consolidates all essential student activities into a single, interactive interface.

---

## 🎯 Objective

Design and develop a **web-based application** that serves as a centralized platform for students to:

* Track academic and personal tasks
* Stay updated with campus events
* Receive timely notifications
* Collaborate and engage with peers

The solution should be **interactive, scalable, and user-centric**, leveraging modern frontend frameworks such as React.

---

## 👥 Target Users

* Students (primary users)
* Faculty / Administrators (secondary users)

---

## ⚙️ Functional Requirements

### 1. User Authentication & Role Management

* Secure login and registration
* Role-based access (Student / Admin)

---

### 2. Personalized Dashboard

* Overview of:

  * Tasks & deadlines
  * Upcoming events
  * Notifications

---

### 3. Task & Deadline Management

* Create, update, delete tasks
* Categorization (Academic / Personal / Exams)
* Deadline tracking

---

### 4. Event Management System

* Admins can create and manage events
* Students can:

  * View event details
  * Interact (like/comment/register)

---

### 5. Notification System

* Alerts for:

  * Upcoming deadlines
  * New events
* Real-time or near real-time updates

---

### 6. Search & Filtering

* Filter tasks/events based on:

  * Date
  * Category
  * Priority

---

## 🚀 Expected Outcomes

Participants should deliver:

* A fully functional web application
* Responsive and intuitive UI/UX
* Efficient state and data handling
* Clean and modular code architecture

---

## 🛠️ Technical Constraints / Suggestions

### Mandatory:

* Frontend: React.js
* Use of Hooks (`useState`, `useEffect`, etc.)
* Component-based architecture

### Optional but Recommended:

* Backend: Node.js / Express / Firebase
* Database: MongoDB / Firestore
* Real-time features (WebSockets / Firebase)
