# 📄 **ASSIGNMENT: HTML STRUCTURE & SEMANTICS CHALLENGE**

---

## 🧾 **Title**

**Design and Develop a Semantic Blog Webpage using HTML**

---

## 🎯 **Objective**

To evaluate your understanding of:

* HTML structure (boilerplate)
* Semantic elements
* Forms and input handling
* Accessibility principles
* Tables and media usage

---

## ⏱️ **Duration**

**2 Hours (Strict Time Limit)**

---

## ⚙️ **Instructions**

* Use **only HTML5**
* Do **NOT** use:

  * CSS
  * JavaScript
  * Tailwind or any framework
* Follow proper indentation and clean code practices
* Use only **semantic elements (no `<div>`)**

---

## 🚫 **Constraints (Mandatory)**

1. Use complete HTML boilerplate:

   * `<!DOCTYPE html>`
   * `<html lang="">`
   * `<meta charset>`
   * `<meta viewport>`

2. Do NOT use `<div>` anywhere

3. Accessibility requirements:

   * Every `<input>` must have a `<label>`
   * All `<img>` must include `alt`
   * Maintain proper heading hierarchy (`h1 → h6`)

4. Use the following elements at least once:

   * `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`
   * `form`, `input`, `textarea`, `select`, `button`
   * `table`
   * `img`
   * `a`

---

## 🏗️ **Task Description**

Create a **single webpage** with the following structure:

---

### 🔹 **1. Header Section**

* Website title
* Navigation bar with links:

  * Home
  * Blogs
  * Contact

---

### 🔹 **2. Main Section**

---

#### 🟢 **A. Blog Section**

* Create **2 blog articles**

Each article must include:

* Title (`h2`)
* Author name and date
* At least one paragraph
* An image with `alt` text
* A “Read More” link

---

#### 🟢 **B. Sidebar Section (`aside`)**

Include:

* List of “Recent Posts”
* List of “Categories”

---

#### 🟢 **C. Table Section**

Create a table titled:
**“Top 3 Articles”**

Include columns:

* Article Title
* Views
* Date

---

#### 🟢 **D. Contact Form Section**

Form must include:

* Name (text input)
* Email (email input)
* Message (`textarea`)
* Gender (radio buttons)
* Interests (checkboxes)
* Country (dropdown/select)
* Submit button

Additional requirements:

* Use `required` attribute where necessary
* Use `placeholder` in inputs

---

### 🔹 **3. Footer Section**

* Copyright information
* At least one link
* Use HTML entity (`&copy;`)

---

## ⭐ **Bonus Requirements (Optional but Recommended)**

* Use `<hr>` appropriately
* Use `<pre>` once
* Use `<sup>` or `<sub>` somewhere
* Use `<article>` and `<section>` meaningfully (not randomly)

---

By completing this assignment, you should be able to:
