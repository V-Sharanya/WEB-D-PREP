🟢 LEVEL 1: Basic DOM Access
✅ Task 1: Change Text
🎯 Goal:

Select an element and change its content

📄 HTML:
<h1 id="title">Hello</h1>
<button id="btn">Change Text</button>
🧩 Task:

When button is clicked → change text to:

Welcome to JavaScript

✅ Task 2: Change Style
🎯 Goal:

Modify CSS using JS

📄 HTML:
<p id="text">I am learning JS</p>
<button id="colorBtn">Change Color</button>
🧩 Task:

On click:

Text color → red
Background → yellow

✅ Task 3: Toggle Content
🎯 Goal:

Switch between two values

📄 HTML:
<h2 id="status">OFF</h2>
<button id="toggleBtn">Toggle</button>
🧩 Task:

Click → toggle between:

OFF → ON → OFF → ON ...
